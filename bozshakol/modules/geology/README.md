# Модуль «геология, качество руды, буровзрывные работы» (geology) — участник №3

Сервис `bz-geology` (Python, `main.py`). Владеет двойниками из `twins.json`:
`face-01…06` (3 сульфидных, 1 глинистый, 2 вскрышных — допущение), `drill-01…03`.

Что делает заглушка (замените логику, не меняя протокол из `contract/README.md`):

- у забоев содержание меди и золота, доля глины около средних 2025 года (0,39 % Cu, 0,19 г/т)
  с медленным дрейфом; крупность после взрыва P80, коэффициент скорости погрузки, крепость;
- остаток тонн забоя уменьшается по разнице накопительного `loaded_total` экскаватора,
  который стоит в этом забое (читается через платформу);
- рекомендуемый пункт разгрузки по типу руды и доле глины (порог 30 %);
- буровые станки перемещаются по блокам и наращивают счётчики метров и скважин;
- сценарии: `clay_face` (параметры `face`, `clay_pct`), `bad_blast` (параметры `face`, `p80_mm`).

Свои файлы: `main.py`, `twins.json`, `compose.yml`, `Dockerfile`, `requirements.txt`, этот README,
`web/layers/geology.js`, `grafana/geology.json`. Новые признаки описывайте здесь.
