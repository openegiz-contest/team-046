# Данные: гранулометрия взорванной горной массы, карьер El Aljibe

Подвыборка открытого набора данных для проверки порядка величин крупности после взрыва (модуль geology).

- **Название:** Fragmentation from 3D drone image analysis in El Aljibe quarry (версия v1, 15 февраля 2024)
- **Авторы:** Segarra, Pablo; Sanchidrián, José A.; Pötsch, Markus; Iglesias, Luis; Gaich, Andreas; Bernardini, Maurizio
- **Источник:** Zenodo, https://zenodo.org/records/10666378; DOI 10.5281/zenodo.10666378.
  Набор взят со страницы данных OpenEgiz https://openegiz-contest.github.io/data/
- **Лицензия:** Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/
  — при использовании нужна ссылка на авторов и источник (она здесь).
- **Что в наборе:** 12 файлов `MSA_B1.txt … MSA_B12.txt`, по одному на взрыв; первый столбец — размер куска, мм, второй — процент прохождения
  (в трёх файлах этого репозитория значения второго столбца лежат от 0 до 1, последняя строка — 1, то есть как доля); получены модулем Fragmenter 2.0.0 (3GSM)
  по фотограмметрическим моделям развала. Использованы в работе Segarra и др., 2024 (DOI 10.1007/s00603-024-03765-1).

## Что изменено

1. **Подвыборка:** из 12 файлов оставлены три — `MSA_B1.txt`, `MSA_B6.txt`, `MSA_B8.txt` (B1 и B6 — типичные по крупности,
   B8 — самый крупный по P80); сами файлы **не изменены**, формат тот же (CSV без заголовка: `размер_мм,прохождение`).
   Единственное изменение при коммите в репозиторий: переводы строк приведены к LF (в исходных файлах CRLF); содержимое
   (числа) не менялось.
2. Сводка по всем 12 взрывам набора посчитана нами линейной интерполяцией по кривой (размер, при котором проходит 50 % и 80 %); в репозитории лежат файлы трёх взрывов (B1, B6, B8), для остальных девяти — исходные файлы набора на Zenodo:

## Как используется

Это измеренный ориентир порядка величин крупности после взрыва. Параметры взрывов El Aljibe (диаметр скважины, сетка,
заряд) в набор не входят — они в статье, — поэтому подогнать по этим данным сдвиг коэффициента породы A модели
Кузнецова–Рамлера нельзя; модуль geology такой подгонки не делает (см. README модуля, разделы 2 «Взрывание» и 8).
