# Данные: гранулометрия взорванной горной массы, карьер El Aljibe

Подвыборка открытого набора данных для проверки порядка величин крупности после взрыва (модуль geology).

- **Название:** Fragmentation from 3D drone image analysis in El Aljibe quarry
- **Авторы:** Pablo Segarra, José A. Sanchidrián, Markus Pötsch, Luis Iglesias, Andreas Gaich, Maurizio Bernardini
- **Источник:** Zenodo, https://zenodo.org/records/10666378 (DOI 10.5281/zenodo.10666378), дата публикации 15.02.2024.
  Набор взят со страницы данных конкурса https://openegiz-contest.github.io/data/
- **Лицензия:** Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/
  — при использовании нужна ссылка на авторов и источник (она здесь).
- **Что в наборе:** распределения размеров кусков по фотограмметрическим моделям развала (Fragmenter 2.0.0, 3GSM),
  12 взрывов в карьере El Aljibe (файлы `MSA_B1.txt … MSA_B12.txt`; два столбца: размер куска, мм, и доля прошедшего
  через сито от 0 до 1). Использованы в работе Segarra и др., 2024 (DOI 10.1007/s00603-024-03765-1).

## Как используется

Это измеренный ориентир порядка величин крупности после взрыва. Параметры взрывов El Aljibe (диаметр скважины, сетка,
заряд) в набор не входят — они в статье, — поэтому подогнать по этим данным сдвиг коэффициента породы A модели
Кузнецова–Рамлера нельзя; модуль geology такой подгонки не делает (см. README модуля, раздел про буровзрывные работы).
