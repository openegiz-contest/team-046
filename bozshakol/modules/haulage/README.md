# Модуль «транспорт и диспетчеризация» (haulage) — участник №2

Сервис `bz-haulage` (Python, `main.py`). Владеет двойниками из `twins.json`:
`truck-01…28`, `excavator-01…06`, `dispatch`, `road-ramp-1`, `road-ramp-2`, `road-crusher`, `dump-waste-1`.

Что делает заглушка (замените логику, не меняя протокол из `contract/README.md`):

- самосвалы ездят по дорогам из `core/geometry.json` (кратчайший путь по графу) между экскаваторами
  и пунктами разгрузки — дробилка, склад глинистой руды, отвал; гружёный и на подъёме — медленнее;
- очереди у экскаватора и на разгрузке, погрузка по ковшам, разгрузка;
- закреплённое распределение: каждый самосвал приписан к экскаватору; в режиме `auto` при поломке
  экскаватора или закрытии дороги самосвал переходит к другому экскаватору с тем же типом груза;
- читает через платформу: `face-*` (содержание, доля глины, скорость погрузки, пункт разгрузки),
  `crusher-01.accepting`, `stockpile-clay.accepting`, `mine.speed_limit`, `scenarios`;
- публикует накопительные счётчики доставок в `dispatch` и отгрузки в `excavator-*`;
- сценарии: `dispatch_off`, `road_closed` (параметр `road`), `excavator_down` (параметр `excavator`).

Свои файлы: `main.py`, `twins.json`, `compose.yml`, `Dockerfile`, `requirements.txt`, этот README,
`web/layers/haulage.js`, `grafana/haulage.json`. Новые признаки описывайте здесь.
